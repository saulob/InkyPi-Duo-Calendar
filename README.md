# Duo Calendar Plugin for InkyPi

A clean calendar plugin with a large date focus, visually inspired by the iPhone Duo calendar interface and optimized for e-paper displays

Duo Calendar provides a simple monthly calendar designed for quick readability, with a strong focus on the current date and a minimal visual layout

## Install

Install the plugin using the InkyPi CLI:

    inkypi plugin install duo_calendar https://github.com/saulob/InkyPi-Duo-Calendar

This plugin is an extension for the [InkyPi](https://github.com/fatihak/InkyPi) e-paper display frame and includes the following features:

## Features

* Large current date display
* Monthly calendar view
* Current day highlighting
* Clean and minimal layout
* Horizontal and vertical layout support
* Multi-language support
* Configurable colors
* Optimized typography and spacing for e-paper displays
* No external APIs required

## Settings

* Language selection
* Primary color
* Secondary color
* Highlight color
* Layout and visual customization

## UI

* Large date focus for quick readability
* Minimal calendar grid
* Layout automatically adapts to different screen orientations
* High contrast rendering suitable for e-paper displays
* Visual style inspired by the iPhone Duo calendar interface

## Notes

* No external APIs used
* Fully self-contained
* Designed for quick glance scenarios
* Works with horizontal and vertical InkyPi layouts
* Optimized for e-paper readability
